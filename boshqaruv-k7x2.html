Ulanish

Buyurtmalar Telegram’ga kelishi va statistika yig‘ilishi uchun bitta bepul server kerak.

1. Serverni yarating (bir marta, ~10 daqiqa)

  1. Cloudflare’da bepul hisob oching → Workers & Pages → Create → Create Worker → Deploy → Edit code.
  2. Ichidagi hamma kodni o‘chirib, saytdagi worker/worker.js faylining ichidagisini joylang va Deploy bosing.
  3. Storage & Databases → D1 SQL Database → Create (nom: topibber). Worker → Settings → Bindings → Add → D1 database: o‘zgaruvchi nomi aynan DB, database — yaratganingiz. Jadvallarni qo‘lda yaratish shart emas.
  4. Settings → Variables and Secrets → Add (turi Secret): BOT_TOKEN (BotFather bergan token), CHAT_ID (pastda topiladi), ADMIN_KEY (o‘zingiz o‘ylab topgan uzun parol, kamida 20 belgi).
  5. Worker manzilini (https://…workers.dev) pastga qo‘ying.

Bot yaratish: Telegram’da @BotFather → /newbot. Keyin o‘z botingizga kirib /start bosing. Chat ID ni “Chat ID ni topish” tugmasi bilan toping — token faqat shu tugma uchun vaqtincha so‘raladi va hech qayerda saqlanmaydi.

2. Manzil va kalit

Chat ID ni topish ixtiyoriy yordamchi

Ulangandan keyin Nashr qilish bo‘limidan yangi data.js ni yuklab, saytga qo‘ying — Worker manzili saytga shunda yetib boradi. Manzil bo‘sh bo‘lsa, forma demo rejimda ishlaydi va statistika yig‘ilmaydi.
